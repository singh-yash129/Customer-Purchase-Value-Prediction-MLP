Overview

What is this project?

An end-to-end machine learning pipeline that predicts the total purchase spend of a user session, helping e-commerce businesses identify and target high-value customers with precision.

Zero-Inflated Target

Most sessions have zero purchase value. The model and post-processing pipeline are specifically designed to handle this skewed distribution gracefully.

Behavioral Signals

Leverages session-level behavioral data — page views, bounce rate, device type, traffic source — to model purchasing intent.

Deep Learning Core

Multi-Layer Perceptron architecture with fully connected layers and ReLU activations to capture complex non-linear feature interactions.

Post-Processing & Evaluation

Clamp negatives to zero → R² Score evaluation → submission ready CSV output.

post_process.py 
import numpy as np
from sklearn.neural_network import MLPRegressor

# Train the MLP model
mlp = MLPRegressor(
    hidden_layer_sizes=(256, 128, 64),
    activation='relu',
    max_iter=500,
    early_stopping=True
)
mlp.fit(X_train, y_train)

# Predict & clamp negatives → zero
predictions = mlp.predict(X_test)
predictions[predictions < 0] = 0

# Evaluate with R² Score
from sklearn.metrics import r2_score
score = r2_score(y_test, predictions)
print(f"R² Score: {score:.4f}")

Challenges & Observations

⚠️
Highly Zero-Inflated Target

Most sessions result in zero spend, creating extreme class imbalance that degrades naive models.

🔍
Dual-Task Nature

The model implicitly performs both purchase classification and value regression simultaneously.

💡
Outlier Sensitivity

R² metric is heavily influenced by high-spending outliers, requiring careful residual analysis.

🔗
Data Leakage Risk

Session-end features can inadvertently leak future information — handled via strict train/test splitting.
