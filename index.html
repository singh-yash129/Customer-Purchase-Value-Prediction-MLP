Overview

What is this project?

A Kaggle competition pipeline (Engage 2: Value from Clicks to Conversions) that predicts session-level purchase value across 116K real e-commerce sessions — comparing 15+ models and selecting the best via R² evaluation.

Zero-Inflated Target

Most sessions have zero purchase value. The model and post-processing pipeline are specifically designed to handle this skewed distribution gracefully.

Behavioral Signals

Leverages session-level behavioral data — page views, bounce rate, device type, traffic source — to model purchasing intent.

Gradient Boosting Wins

After benchmarking 15+ models — Linear Regression, SGD, KNN, SVM, MLP, Bagging, and Voting ensembles — a refined XGBoost with feature engineering achieved the best R² of 0.3675.

Pipeline

Technical Highlights

Full pipeline from raw Kaggle session data to final predictions, with 15+ models benchmarked via 5-fold cross-validation and R² evaluation.

Raw Session Data (Kaggle)

116,023 train / 29,006 test sessions × 52 columns — numerical, categorical, high-cardinality, and time-based features.

Preprocessing Pipeline

Drop 9 high-missing columns (>50%), median imputation, One-Hot Encoding → 1,630 features, StandardScaler, SelectKBest (k=50).

Feature Engineering + Multi-Model Training

Date decomposition (year/month/day/dayofweek) + session_hour/minute → 513+ features. 15+ models trained with RandomizedSearchCV.

Post-Processing & Final Submission

Clamp predictions < 0 to zero → R² evaluation → best model (XGBoost, R²=0.3675) retrained on full data → submission.csv.

best_model.py 
from xgboost import XGBRegressor
from sklearn.metrics import r2_score

# Best params from RandomizedSearchCV (n_iter=50, cv=5)
model = XGBRegressor(
    random_state=39,
    n_estimators=340,
    learning_rate=0.050,
    max_depth=9,
    subsample=0.726,
    colsample_bytree=0.644,
    gamma=0.220
)
model.fit(X_train_processed_fe, y_train)

# Clamp negatives → zero (real-world constraint)
predictions = model.predict(X_val_processed_fe)
predictions[predictions < 0] = 0

# Best R² on validation set
score = r2_score(y_val, predictions)
print(f"R² Score: {score:.4f}")
# → R² Score: 0.3675

Challenges & Observations

⚠️
Highly Zero-Inflated Target

Median purchaseValue = 0 (50th percentile). Most sessions never convert, making naive models default to near-zero predictions.

🔍
MLP Underperformed (R² = −0.010)

Despite being the project's name, the MLP Regressor underperformed. XGBoost with feature engineering was the clear winner at R² 0.3675.

💡
Outlier Sensitivity

R² is heavily influenced by high-value sessions (e.g. ₹88,950,000) — a single outlier can swing scores by several points.

🔗
9 Columns Dropped (>50% missing)

Including totals.bounces, trafficSource.keyword, trafficSource.adContent, and 6 others — all dropped to avoid imputation bias.
